# Quick-Start Guide

**Get from installation to your first invoice in ten minutes.**

## 1. Set up your shop (2 minutes)

- **Settings → Shop profile**: shop name, address, phone, email, logo.
- **Settings → Regional**: country, currency, number and date format, time zone.
- **Settings → Tax**: switch tax on and enter the rate, or leave it off.

## 2. Add a phone (1 minute)

1. Open **Mobile Inventory** and click **Add mobile**.
2. Enter brand, model, **IMEI 1**, purchase price and selling price.
3. Click **Save**. The phone receives a Stock ID such as `MS-0001`.

The app refuses an IMEI that already exists, so the same phone can never be entered twice.

## 3. Add accessories (1 minute)

Open **Accessories → Add accessory**. Enter the name, category, prices, opening quantity and the minimum stock level at which you want to be warned.

## 4. Make a sale (1 minute)

1. Click **New Sale** (or press **Ctrl + N**).
2. Type part of the model or IMEI and click the phone. Add accessories from the **Accessories** tab.
3. Choose the customer, or leave **Walk-in customer**.
4. Enter a discount if you are giving one.
5. Enter the **Amount received**. Less than the total means the rest goes on the customer's credit.
6. Click **Complete sale** (or **Ctrl + Enter**).

The invoice opens immediately. **Print** it, **Save as PDF**, or send the details by **WhatsApp**.

## 5. Collect a credit payment

Open **Credit Book**, find the customer and click **Record payment**. A receipt is produced and the balance updates.

## 6. Take a trade-in

On the New Sale screen click **Add trade-in / exchange phone**. The trade-in value is deducted from what the customer pays, and the phone is added to **Exchange / Used Stock** automatically, ready to be resold.

## 7. Record expenses

**Expenses → Add expense** for rent, electricity, salaries and so on. Expenses reduce **net profit** on the dashboard and in reports.

## 8. Back up

**Backup & Restore → Back up now.** Automatic daily backups are on by default. For real safety, set the backup folder to a USB drive or a cloud-synced folder.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + K | Search everything |
| Ctrl + N | New sale |
| Ctrl + Enter | Complete the sale |
| Ctrl + 1 … 9 | Open the first nine menu items |
| Ctrl + B | Back up now |
| / | Search the current table |
| Esc | Close the current window |
| F1 | Show all shortcuts |
