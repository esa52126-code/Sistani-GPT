# Licence Activation

## Where is my licence key?

Your key comes with your purchase: in the receipt email or on the download page of the store where you bought the software, or directly from the seller.

There are two kinds of key. You do not need to know which one you have; the app recognises both.

| Key looks like | Needs internet to activate? |
|---|---|
| Long key starting with `MSM1-` | No, never |
| Short key such as `1A2B3C4D-5E6F7A8B-9C0D1E2F-3A4B5C6D` (Gumroad) | Yes, once |

## Activating

1. Open **Settings → Licence**.
2. **Copy and paste** the whole key into the box (long keys should never be typed by hand) and click **Activate**.
3. The status changes to **Licensed**.

## Device code

Some keys are made for one specific computer. If the seller asks for your **device code**, you will find it in **Settings → Licence** (for example `A1B2-C3D4`). Send it to the seller and you will receive a key for that computer.

## Trial

Without a key the app runs as a full-featured trial for **{{trialDays}} days**.

## Working offline

The software is designed for shops with unreliable internet. Everyday work — inventory, sales, invoices, reports, backups — needs **no internet at all**.

- **`MSM1-` keys** are checked on your own computer. They never need the internet.
- **Gumroad keys** are re-checked quietly about once a week when a connection happens to be available. The app keeps working for up to **{{graceDays}} days** without a successful check, then asks you to connect once and click **Verify now**.

**Your data is never locked.** If the trial ends, the offline allowance runs out, or a licence is refunded, the app switches to a restricted mode in which you can still **open, view, search, print, export and back up everything**. Only creating new records is paused until the licence is valid again.

## Messages you may see

| Message | What it means | What to do |
|---|---|---|
| This licence key is not valid for Mobile Shop Manager Pro | The key was mistyped or belongs to another product | Copy and paste it again from your receipt |
| The licence key is incomplete | Part of a long key was not copied | Copy the whole key, from `MSM1` to the last character |
| This licence key was issued for another computer | The key is locked to a different device code | Send the device code shown in the message to the seller |
| Could not reach the licence server | No internet connection, or a firewall is blocking it | Connect and try again; allow `api.gumroad.com` |
| …because the purchase was refunded | The order was refunded or charged back | Purchase again or contact support |
| …because the licence was disabled by the seller | The seller disabled the key | Contact support |
| …already been activated the maximum number of times | The key is in use on other computers | Remove it from an old computer or contact support |
| Verification needed | More than {{graceDays}} days since the last online check | Connect to the internet and click **Verify now** |

## Moving to a new computer

1. On the old computer: **Backup & Restore → Back up now**, and copy the backup file to a USB drive.
2. On the old computer: **Settings → Licence → Remove licence from this computer**.
3. Install the app on the new computer and activate with the same key. If your key is locked to a device code, send the new computer's device code to the seller for a replacement key.
4. **Backup & Restore → Restore from a backup file…** and choose your backup.

## Privacy

With an `MSM1-` key nothing is sent over the internet at all. With a Gumroad key, only the key itself is sent to Gumroad's licence service to confirm the purchase. No shop, customer or sales data ever leaves your computer.
