# Changelog

## Version 1.1.0

- Universal licence keys (`MSM1-…`) that activate without internet and can be sold on any platform
- Optional device-locked keys, with the device code shown in Settings → Licence
- Gumroad keys continue to work

## Version 1.0.0 — first release

- Mobile inventory with automatic Stock IDs and IMEI uniqueness across new and used stock
- Accessories inventory with purchases, stock adjustments, weighted-average cost and low-stock alerts
- Fast New Sale screen: phones, accessories, used phones, discounts, tax, trade-ins and part payment
- Customer management, credit book, payment receipts and printable statements
- Exchange / used stock with resale profit
- Expenses and supplier ledger (purchases, payments, payable)
- Dashboard with date filters, charts, low-stock list and recent transactions
- Thirteen reports with print, PDF and CSV export
- A4 invoices and 80 mm thermal receipts; WhatsApp sharing
- Global search (Ctrl + K)
- Configurable currency, number format, date and time format, time zone and first day of week
- Configurable tax: inclusive or exclusive, custom label and rate, tax-exempt sales
- Manual and automatic backups, validated restore with safety backup, CSV import and export
- Optional password protection
- Gumroad licence activation with trial and offline allowance
- English interface, with starter translations for Urdu, Arabic, Spanish, French, German and Hindi and right-to-left layout
